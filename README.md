# CrackMe

This is the fifth challenge from [rehayilmazlar.com](https://rehayilmazlar.com), featuring a reverse-engineering crackme written in x86 assembly.

Analyze `CrackMe.exe`, understand how it validates the entered serial, and find the correct one. Once you find the serial, submit it on the website to complete the challenge.

This challenge is intended for educational use and reverse-engineering practice.
