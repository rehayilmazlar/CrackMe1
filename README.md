# CrackMe #5

This is the fifth reverse-engineering challenge from [rehayilmazlar.com](https://rehayilmazlar.com).

`CrackMe.exe` is a 32-bit Windows crackme written in x86 assembly with MASM. Analyze the executable, understand how it validates the entered serial, and find the correct solution.

This challenge is intended for educational use and reverse-engineering practice.
